# Fargo's Mutant Mod

Fargo's Mutant Mod is a Quality of Life/content mod for **Terraria**.

This repository contains the source code for Fargo's Mutant Mod, maintained by the Fargo Team.

## Installation

The recommended way to install Fargo's Mutant Mod is through the official Steam Workshop or the in-game tModLoader Mod Browser.

- [Steam Workshop](https://steamcommunity.com/workshop/filedetails/?id=2570931073)


## Development

Fargo's Souls Mod is developed in C# using [tModLoader](https://github.com/tModLoader/tModLoader).

This repository is primarily intended for the development and maintenance of the official mod.

Bug reports and suggestions can be submitted through the repository's [Issues](https://github.com/Fargo-Team/FargosMutantMod/issues) page or the Fargo Discord.
